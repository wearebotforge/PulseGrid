# Mistake Bot

A Discord moderation bot for the PulseGrid server using the Vibex API.

## Features

- Moderation commands (kick, ban, mute, warn)
- Integration with PulseGrid server APIs
- Vibex API powered functionalities
- Easy to extend and customize

## Getting Started

### Prerequisites

- Node.js v16 or higher
- npm or yarn
- Discord bot token
- API keys for PulseGrid and Vibex
